# BundleBaskets.com

Multi-page site + app wireframes for the service-bundling gift basket rewards platform.

## Pages
- `index.html` — Home
- `how-it-works.html` — Process explanation
- `baskets.html` — Tiers & categories
- `for-providers.html` — Banking, telecom, home security, medical, liquor stores & manufacturers, etc.
- `for-makers.html` — Basket makers
- `app.html` — App wireframes & UI previews
- `contact.html` — Early access form
- `styles.css` — Shared styles

## Age Verification
- `age-verification.js` — Client-side prototype gate for liquor baskets (21+).
- Production should integrate a certified API (AgeChecker.Net, Veratad, Avalara Beverage Alcohol, or Yoti) that handles state-specific rules and audit trails.
